# Automated Validator Flawed Logic Example

This Python script simulates a scenario where two independent data sources produce outputs, and an automated validator checks for consistency. The validator's logic is flawed, causing it to repeatedly flag inconsistencies even when the sources might be legitimately different or the validator's criteria are too rigid, illustrating the 'blind spot' of automated controls.

## Language

`python`

## How to Run

Save the code as `flawed_validator.py` and run it from your terminal using: `python flawed_validator.py`
